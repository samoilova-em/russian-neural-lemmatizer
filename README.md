# Russian Neural Lemmatizer

Neural morphological analyzer for the Russian language that performs lemmatization (reducing words to their dictionary form) and Part-of-Speech (POS) tagging. Built from scratch using PyTorch.

## Описание

Этот проект представляет собой нейросетевой морфологический анализатор для русского языка. Модель принимает на вход сырой текст и для каждого слова предсказывает:
 - **Часть речи (POS-tag)**
 - **Лемму** (начальную форму слова)

В основе проекта лежит двухуровневая архитектура на базе BiLSTM. Такой подход позволяет модели одновременно анализировать внутреннюю морфологическую структуру слова (на уровне символов) и широкий лингвистический контекст предложения, что критически важно для качественного морфологического разбора.
Более подробное описание архитектуры, процесса обучения и экспериметов представлено в ноутбуке.

## Особенности реализации

 - Коррекция аннотаций и словарная интеграция:
 В исходном обучающем датасете [OpenCorpora](https://web.archive.org/web/20160322215834/http://opencorpora.org/files/export/annot/annot.opcorpora.xml.bz2) наблюдалась системная особенность разметки глаголов: в качестве леммы указывалась форма прошедшего времени мужского рода, а не инфинитив. Для устранения этой проблемы и повышения надежности был разработан кастомный модуль предобработки. Он сверяет данные с эталонным морфологическим словарем [OpenCorpora](https://web.archive.org/web/20150208151908/http://opencorpora.org/files/export/dict/dict.opcorpora.txt.bz2), принудительно приводя лемму глагола к корректному инфинитиву, а часть речи (POS-тег) определяет как глагол(V). Это позволило значительно повысить качество предсказаний без переобучения модели.

 - Учет контекста для разрешения омонимии: 
 Использование двунаправленной рекуррентной сети (BiLSTM) на уровне предложений позволяет модели различать омонимы (например, существительные и глаголы с одинаковым написанием), опираясь на синтаксическое окружение слова.

## Результаты

Модель была обучена на корпусе  [OpenCorpora](https://web.archive.org/web/20160322215834/http://opencorpora.org/files/export/annot/annot.opcorpora.xml.bz2). На отложенной тестовой выборке достигнуты следующие метрики:
- **POS Accuracy**: ~85.0%
- **Lemma Accuracy**: ~81.5%

Несмотря на то, что словари не содержали сленговых слов, модель в целом верно их распознает, по характерным суффиксам и позиции в предложении.

*(Пример: "Я загуглил этот мем и начал рофлить с друзьями" → "Я{я=NI} загуглил{загуглять=V} этот{этот=A} мем{ме=NI} и{и=CONJ} начал{начал=V} рофлить{ролить=V} с{с=PR} друзьями{друмя=S}")*

## Установка и запуск

**

1. **Клонирование репозитория**
```bash
git clone https://github.com/samoilova-em/russian-neural-lemmatizer.git
cd russian-neural-lemmatizer
```
2. **Установка зависимостей**
```bash
pip install -r requirements.txt
```
3. **Работа с данными**
В репозитории представлена демоверсия датасета для быстрого тестирования пайплайна. Для полноценного обучения на всем корпусе скачайте файлы по архивным ссылкам (основной сайт OpenCorpora может быть недоступен)  и поместите их в папку `data/`: основной датасет - [OpenCorpora](https://web.archive.org/web/20160322215834/http://opencorpora.org/files/export/annot/annot.opcorpora.xml.bz2), морфологический словарь (необходим для коррекции обучающего датасета) - [OpenCorpora](https://web.archive.org/web/20150208151908/http://opencorpora.org/files/export/dict/dict.opcorpora.txt.bz2).

4. **Запуск обучения**
```bash
python main.py
```
Скрипт автоматически проверит наличие данных, инициализирует модель и запустит процесс обучения. После завершения чекпоинт будет сохранен в папку `checkpoints/`.

### Интерфейс

Для анализа текста без обучения модели с нуля используйте скрипт `interface.py`:

```bash
# Интерактивный режим
python interface.py

# Анализ одного предложения
python interface.py --sentence "Сохранится ли градус дискуссии в новом сезоне?"

# С использованием своего чекпоинта
python interface.py --checkpoint checkpoints/morph_checkpoint.pth
```

```text
│   ├── model.py             # Архитектура BiLSTM (Encoder + Decoder)

│   └── predict.py           # Логика инференса для новых текстов
├── data/                    # Датасеты
└── checkpoints/             # Сохраненные веса моделей
```
