# Ответы на ключевые вопросы

## Проблема

Автоматизированное преобразование визуальных учебных материалов в машиночитаемые графы знаний.

## Актуальность

Учебные схемы являются распространённым способом представления знаний в образовательных материалах. Они позволяют наглядно отображать взаимосвязи между понятиями, последовательности процессов и другие виды структурированной информации. Однако поиск и повторное использование таких изображений по их содержанию затруднены отсутствием явного машиночитаемого представления содержащихся в них объектов и семантических связей.

Существующие методы компьютерного зрения позволяют решать отдельные задачи распознавания текстовых и графических элементов, однако полноценная интерпретация схем требует не только обнаружения отдельных объектов, но и установления отношений между ними с учётом их визуального расположения и семантического контекста. Обзоры современных методов оцифровки сложных документов и понимания диаграмм демонстрируют сохраняющуюся сложность комплексного восстановления структуры визуальных материалов [1, 2].

Автоматизированное извлечение структурированной информации из изображений является активно развивающимся направлением исследований. Современные работы охватывают распознавание и интерпретацию диаграмм, извлечение семантических связей между визуальными элементами, а также построение графов знаний непосредственно на основе изображений, в том числе с использованием моделей, обучаемых на неразмеченных данных [2–4].

Таким образом, разработка нейросетевого модуля для распознавания и интерпретации элементов учебных схем с последующим преобразованием извлечённой информации в графы знаний является актуальной научно-практической задачей. Её решение позволит снизить объём ручной обработки образовательных материалов, создать основу для автоматизированного формирования структурированных баз знаний, которые могут использоваться в интеллектуальных образовательных системах, и облегчить поиск изображений по их содержанию.

## Объект исследования

Процесс автоматизированного извлечения знаний из изображений учебных схем.

## Предмет исследования

Точность извлечения семантической информации из визуальных учебных материалов.

## Цель дипломного исследования

Разработать нейросетевой модуль для распознавания элементов учебных схем с последующим преобразованием извлечённой информации в графы знаний.

## Цель на текущий семестр

Провести анализ предметной области и существующих аналогов, обосновать выбор нейросетевых методов для извлечения данных из учебных схем и разработать архитектуру модуля построения графа знаний.

## Задачи

1. Сформировать требования к модулю распознаванию структур на изображениях на основе обзора существующих моделей, критериев их сравнения и результатов этого сравнения.
2. Сформировать и подготовить набор данных из учебных схем с разметкой визуальных элементов и семантических связей между ними.
3. Разработать архитектуру нейросетевого модуля для детектирования объектов на схемах и извлечения семантических связей между ними.
4. Реализовать алгоритм преобразования распознанных визуальных элементов в структурированный формат графа знаний.
5. Провести экспериментальное исследование разработанного модуля, оценить точность извлечения данных и качество построения графов знаний на тестовой выборке.
